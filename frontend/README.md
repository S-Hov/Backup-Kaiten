# Клиент

ES-модули и компонент `<kaiten-card>`, без обязательной сборки.

- `api.js` — единственная точка обращения к серверному API.
- `app.js` — поиск, навигация, выбор копии.
- `card-component.js` — отображение переданного `CardViewModel v1`.
- `rich-text.js` — очистка и отображение Markdown/HTML.
- `styles.css` — оформление.

Клиент обслуживается FastAPI из этой папки. Для будущей отдельной сборки
укажите её каталог в `BOARD_FRONTEND_ROOT`. Компонент не зависит от Python,
SQLAlchemy или структуры файлового архива.
