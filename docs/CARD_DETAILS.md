# Модальное окно рабочей карточки

На главной доске нажмите на карточку. Окно показывает описание, расположение,
тип, участников, ответственного, срок, теги, пользовательские поля, чек-листы,
файлы, ссылки и связанные карточки. В боковой панели — комментарии, перемещения
и события. На узком экране панель располагается под основными сведениями.

Дополнительные даты, размер, подписчики, блокировки и ненормализованные разделы
доступны в раскрываемых блоках. Исходные сведения и замечания резервной копии
сохранены отдельно. Окно пока предназначено для просмотра.

## Навигация

- Рабочая карточка хранится в `?cardId=UUID`; ссылку можно скопировать и открыть напрямую.
- `cardId` отличается от старого `card=SOURCE_ID`, используемого архивом.
- «Назад» закрывает окно или возвращает предыдущую открытую карточку.
- Закрытие: кнопка, Escape или щелчок по затемнённому фону.
- Native dialog удерживает фокус внутри окна и блокирует действия с доской.
- Изображение открывается поверх карточки. Его закрытие сохраняет окно карточки.
- Доступные связанные карточки открываются в том же окне; заглушки обозначены как недоступные.

## Источники данных

`GET /api/v1/cards/{uuid}/detail` возвращает отдельную модель деталей с версией
контракта. Читаются рабочие таблицы: карточка, пользователи и участники, подписчики,
теги, поля и варианты значений, чек-листы, вложения, комментарии, история,
события, связи, ссылки и блокировки. Пакетные выборки используются для авторов
и связанных сущностей. Новый endpoint не перечитывает JSON-папки и не вызывает Kaiten.

Текущие нормализованные строки имеют приоритет перед исходными данными.
Для ещё не нормализованных разделов (например, SLA, учёт времени) используется
сохранённая в `archive_cards.raw` SQL-копия. Снимок выбирается по исходному ID
карточки и origin компании, от новых имён снимков к старым; UUID рабочей карточки
не подменяется исходным ID. Несколько компаний с одинаковыми ID не смешиваются.
Это дополнение исходной копии, а не источник актуальных редактируемых полей.
Локальная карточка без импортированной копии тоже открывается.

Архивные карточки доступны для чтения по UUID; удалённые, отсутствующие и
заглушки возвращают 404. Полнота ограничена фактически сохранённой копией:
невыгруженные разделы и файлы не восстанавливаются автоматически.

`GET /api/v1/attachments/{uuid}/content` выдаёт файл по ключу хранилища из БД,
с проверкой существования и границ каталога. `?download=1` принудительно скачивает
оригинал. HTML, SVG и остальные активные форматы выдаются вложением;
для просмотра разрешены растровые изображения, PDF, видео и аудио.
Пути хранилища не передаются как URL. Разметка карточки и комментариев очищается,
изображения сопоставляются с локальными вложениями; внешние изображения не загружаются.

## Клиент

- `entities/card` — схема и запрос деталей, общий компонент цветных тегов.
- `widgets/card-modal` — представление сведений, комментариев и событий.
- `shared/ui/modal` — native dialog, блокировка прокрутки, фон и закрытие.
- `shared/ui/files`, `shared/ui/rich-text`, `shared/lib/rich-text` — общие части
  просмотра файлов и безопасного текста для архива и рабочей карточки.

Виджет загружается лениво при открытии карточки. TanStack Query разделяет кеш
по UUID, отменяет запрос при закрытии/смене карточки и не подменяет новую
карточку результатом прежнего запроса. Ошибка остаётся внутри окна с повтором
запроса и сообщением Sonner. Данные списка доски и его прокрутка сохраняются.
