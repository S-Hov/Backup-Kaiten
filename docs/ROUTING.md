# Конфиг страниц и навигация

`frontend/src/shared/config/routes.ts` — общие пути `routePaths`, имена
параметров `routeParams` и построители ссылок `routeUrls`. Этот модуль не
импортирует страницы и доступен любому слою FSD.

`frontend/src/app/router/AppRouter.tsx` — таблица `pageRoutes`: путь,
компонент страницы, ленивая загрузка архива и перенаправления. `App.tsx`
подключает BrowserRouter. Неизвестный путь ведёт на главную.

| Адрес | Назначение |
| --- | --- |
| `/` | Рабочая доска из БД |
| `/archive` | Просмотр сохранённых резервных копий |

Параметры рабочей доски:

| Параметр | Значение |
| --- | --- |
| `board` | UUID выбранной доски; без него выбирается первая доступная |
| `cardId` | UUID открытой карточки |
| `view=lists` | Отдельная вертикальная прокрутка каждой колонки |
| `archived=1` | Архивные карточки выбранной доски вместо активных |
| `q` | Поиск по названию, номеру или тегу |

Без `view` используется обычная доска. `readBoardLocation` читает параметры,
`updateBoardParams` объединяет изменения с текущим адресом, сохраняя остальные
параметры. `pages/board/model/use-board-navigation.ts` связывает это с React Router:
открывает карточки, меняет доску, режим, архив и поиск. Фильтры сохраняются при
перезагрузке; навигация назад/вперёд работает через историю браузера.

Для ссылок используйте `routeUrls.board({ board, view: "lists" })` и
`routeUrls.archive()`, для регистрации страниц — `routePaths`. Новая страница
добавляется в `pages`, экспортируется через свой `index.ts` и подключается
в `pageRoutes`. Для нового адреса также нужно добавить серверную выдачу SPA:
сейчас FastAPI отдаёт приложение на `/` и `/archive`.

Старые ссылки `/?snapshot=...&card=...` перенаправляются в `/archive`
с сохранением параметров. `card` — исходный номер архивной карточки,
`cardId` — UUID рабочей карточки: это разные адреса и модели данных.
